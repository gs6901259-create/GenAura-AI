# GenAura AI

GenAura AI is an intelligent influencer marketing and creator intelligence platform designed for brands and agencies to discover, evaluate, and shortlist creators based on deep campaign brief alignment.

## Core Capabilities

- **Creator Discovery & Exploration**: Rich creator directory across platforms (Instagram, YouTube, TikTok, LinkedIn, X) with verified metrics, audience demographics, and rate cards.
- **Explainable Match Scoring**: Deterministic, multi-dimensional scoring engine that quantifies brief-to-creator fit with full explainability.
- **Combined Filtering & Search**: Multi-factor filtering (platform, niche, tier, engagement, budget, brand safety) and real-time text search.
- **Shortlisting & Campaign Planning**: Team shortlists with aggregate budget, reach, and engagement analytics.

## Getting Started

```bash
# Install dependencies
npm install

# Run automated test suite
npm test

# Start the local development server
npm start
```
